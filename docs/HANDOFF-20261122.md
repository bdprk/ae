## 2. 下一步工作（按顺序，不要跳）

### 优先级 1：ADR-0230 下一站——聚合构造 + 所有权效应
`let p = Point { x: 1, y: 2 };` 进 body 路线需要先补 **Frees/所有权**：
body 路线的 `Statement::Return(value, Vec::new())` 恒为空释放表，
而 typed 路线用 `live_owned()` 在出口收集 owned 槽位。无 drop 的
纯标量字段结构体可以先走（`drop_fn == None` 门控）；带 drop 的
（`Guard` 族）与 move 语义留在 typed。参考 ADR-0230 的
「calls and ownership effects」段。

### 优先级 2：泛型/闭包体（ADR-0229 记录的设计边界）
spawn callable 参数（parser.rs:196）需要捕获推断；泛型实例化用
M1.7 模板机制。这两类是梯子最后一段，借用编译器既有 machinery。

### 优先级 3：R3c 类型检查器本体
ADR-0229 梯子的核心：在 resolved tree 上做真正的类型推导/检查，
替代编译器单趟里的类型逻辑。这是最大的弧，建议先写 ADR 拆分。
