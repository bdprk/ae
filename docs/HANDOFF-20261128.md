## 4. 工作方式备忘（本次学到的）

- MSVC 每个 cargo test 二进制都写 .pdb；`debug=0` 后 panic 位置不受影响
  （编译期常量）。恢复调试用 `CARGO_PROFILE_DEV_DEBUG=1`。
- 长跑 fuzz 用私有二进制：`AE_FUZZ_BIN=/tmp/ae-fuzz/ae.exe python
  scripts/diff_fuzz.py --pure-subset --seeds N --jobs 3`；`--seeds` 默认 40，
  `--stop-before` 只是上限。
- cargo test 会 spawn `ae.exe`（编译出来的测试程序）；`taskkill /IM ae.exe`
  会把测试套件一起杀掉，套件跑着时不要清进程。
- 向运行时字符串（C 源文本）插多行内容：按行列表插入，不要字符串替换拼接；
  改完 `cat -A` 查行尾。相互调用的 static inline 先声明被调用者。
- 修语法制导的路由门时，先跑 corpus 门禁确认没有"多接纳但降级器不认"的裂缝
  （本次 f32_char_unit_ptr_usize/first_class_closures 两例）。
