## 6. 坑（本阶段踩过）

- 远端 main 共享：push 前 `git fetch`；非快进就 `rebase origin/main`，重试循环
  （本次 6 次才落地）。绝不 force-push。
- Windows MinGW 无 ASan/UBSan；`--sanitize` 必须 WSL。
- 文档/ledger 是 CRLF；批量改写用 CRLF 感知脚本，否则整文件 diff。
- Bash 工具会转义 `\n`：大段多行 Rust 补丁用 Edit 工具或 `chr(92)` 拼；
  Python heredoc 里别写 `\n` 之外的转义。
- autopush 钩子与手动 push 竞争会产生 `cannot lock ref … expected`；以
  `git ls-remote` 为准，不重复推。
- 纯后端的 `PtrMut(0)` 是占位符：任何 pointee/fn_sig 查表都要 bounds-check。
- 优化器只做块内常量传播；任何 `Deref` 写必须清空常量环境（别名）。
