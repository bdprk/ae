## 6. 坑（本阶段踩过）

- 远端 main 共享：push 前 `git fetch`；非快进就 `rebase origin/main`，重试循环
  （本次 6 次才落地）。绝不 force-push。
- Windows MinGW 无 ASan/UBSan；`--sanitize` 必须 WSL。
- 文档/ledger 是 CRLF；批量改写用 CRLF 感知脚本，否则整文件 diff。
- Bash 工具会转义 `\n`：大段多行 Rust 补丁用 Edit 工具或 `chr(92)` 拼；
  Python heredoc 里别写 `\n` 之外的转义。
- autopush 钩子与手动 push 竞争会产生 `cannot lock ref … expected`；以
  `git ls-remote` 为准，不重复推。
- 纯后端的 `PtrMut(0)` 是占位符：任何 pointee/fn_sig 查表都要 bounds-check。
- 优化器只做块内常量传播；任何 `Deref` 写必须清空常量环境（别名）。
- 纯管线**不跑** drop elaboration：所有 moving position 必须降成
  `Operand::Move`（后端 take 清空源槽），否则保守 `Frees` 会二次释放/泄漏；
  `#[derive(Copy)]` 类型要保持在 `Body.copy_structs/copy_enums` 里，不能 take。
- 用户 `Drop` impl 必须有 live flag（`ae_live`，字段名冲突时追加 `_`），
  否则 moved-from 的槽被 release 时会对零值再调一次用户函数。
- `tests/pure_mir_e2e_p32.rs` 用 `-Wall -Wextra -Werror` 编译：release helper
  即使空体也要 `(void)v;`。
- 结构体里的函数指针要求 `ae_fn_t{sig}` 先于结构体 typedef；fn sig 必须进入
  拓扑序（`TypeDefKey::FnSig`），不能在最后统一打印。
- WSL 里跑 ASan 脚本要写成**脚本文件**再 `bash asan.sh`：`wsl bash -lc '...$f...'`
  的 `$f` 会被外层 Git Bash 提前展开成空串。
- C 的 `(T){ value }` 在 T 是结构体时**不是复制**，而是初始化第一个成员；
  向容器压入结构体值必须用块级临时（`{ T _tmp = value; ... &_tmp; }`）。
- `FieldStore` 覆盖 owned 字段前必须先 release 旧值；唯一例外是字面自赋值
  （`p.name = p.name`），此时跳过释放，避免先释放后存回悬垂指针。
- `vec_index_of` 同时服务于 `&v[i]` 和 `w.cells[i]`（字段接收者读），结果类型
  可能就是元素本身；owned 聚合元素只能作为字段链的临时值，前端禁止把它
  绑到变量，因此按值复制不会产生第二个 owner。
- 向量元素读取的 view 语义：string→`ae_str_view`，struct→指针，nested
  vector→header 拷贝；不要 drop 这些临时值。
- `slice_range` 的 arg0 可能直接是 **vector/array**（`&v[a..b]` 不先建
  slice_of），统一走 `slice_view_of_place` 生成 `ae_slice_view`；slice 本身
  是值，永不 release。
- `ae emit-pure-mir` 是排查 lowering/后端归属的第一工具；synthetic
  intrinsic 会显示成 `fn#<hash>`，对照 `Body.intrinsics` 的注册名。
- 纯后端只链接 runtime bridge 里的符号（`ae_std_alloc`/`ae_std_free`/
  `ae_extern_probe`）；其他 extern 必须继续具名 fail-closed，不要为了
  夹具去加符号。
- ASan 下测 OOM 夹具要加 `ASAN_OPTIONS=allocator_may_return_null=1`，
  否则 ASan 自己 abort，看不到 runtime 的 NULL 分支。
